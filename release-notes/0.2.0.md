**Teria ist jetzt ein eigenständiges Betriebssystem.** Statt als Paket über Switchroot Ubuntu zu laufen, ist Teria 0.2.0 ein komplettes System auf Basis von **Debian 13 trixie (arm64)**, das Ubuntu auf der SD-Karte ersetzt. Vom Switchroot-Projekt kommen nur Kernel, Treiber und Firmware.

### Neu
- **Eigenes rootfs** (#17): Debian trixie arm64, gebaut mit mmdebstrap nativ auf arm64. Xfce-Desktop mit LightDM, NetworkManager, Bluetooth, PulseAudio, SSH, Firefox ESR, deutsche Sprache und Tastatur, Zeitzone Wien.
- **Switchroot-Kernel und L4T** (#21): Kernel 4.9.140-l4t mit Modulen und Firmware aus `switch-bsp`, GPU-Treiber `nvidia-l4t-*` 32.3.1 mit dem dazu passenden Xorg 1.20 und `libx11`, `joycond` sowie die Switch-Regeln für Touch, Audio, Dock und Joystick-Maus. Feste apt-Pins verhindern, dass Debian diese Teile ersetzt.
- **Eigener Bootstack** (#22): `/switchroot/teria/` mit eigenem Hekate-Eintrag, Icon und Bootlogo; Linux-Partition `SWR-TER`.
- **SD-Paket für Hekate** (#18): `teria-0.2.0-sd.zip` mit `switchroot/install/l4t.NN` für **Flash Linux** und `SHA256SUMS`. Kein Skript partitioniert, formatiert oder flasht etwas, und der eMMC wird nie angefasst.
- **Erststart** (#23): Die Partition wird auf die volle Größe gebracht, SSH-Schlüssel und Maschinen-ID werden erzeugt. Anmeldung `teria` / `teria`, das Passwort muss beim ersten Anmelden geändert werden.
- **USB-Teststart** (#25): `extras/bootloader/ini/teria-usb.ini` startet Teria von einem USB-Stick am Dock, Ubuntu bleibt unberührt.
- **Anleitung** (#24): [docs/INSTALLATION.md](https://github.com/gigafrosxh/auto-injector-switch-v1/blob/v0.2.0/docs/INSTALLATION.md): Sicherung, Flash Linux, Teststart, Rückweg zu Ubuntu.

### Geändert
- `teria-base` setzt auf Debian `ID=teria` und `ID_LIKE=debian`, auf Ubuntu bleibt es bei `ID=ubuntu`.
- Der Overlay-Booteintrag aus 0.1.0 (Teria-Logo für den Ubuntu-Kernel) entfällt, `tools/deploy.sh` installiert nur noch das Paket.

### Bekannt
- Noch nicht auf der Switch gebootet: Grafik (Xorg 1.20 aus dem L4T-Repo auf Debian trixie) ist das größte Risiko (#29).

---
**Installation:** `teria-0.2.0-sd.zip` auf die FAT32-Partition der SD-Karte entpacken, in Hekate **Nyx → Tools → Partition SD → Flash Linux**, dann **More configs → Teria**. **Das überschreibt Switchroot Ubuntu.** Vorher sichern, siehe Anleitung.
**Nur das Werkzeug `teria`** für ein bestehendes Switchroot Ubuntu: `teria-base_0.2.0_all.deb`.
**Injector (Windows):** `teria-injector-windows-0.2.0.zip`.
Teria schreibt nie auf den internen eMMC. Nutzung auf eigene Gefahr, nur für eigene Geräte.
