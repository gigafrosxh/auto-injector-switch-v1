Der USB-Gerätemodus startete im trixie-Image nicht, weil dem L4T-Dienst `nv-l4t-usb-device-mode` Werkzeuge fehlten (Exit 127). Das Image bringt jetzt `bridge-utils`, `net-tools` und `isc-dhcp-server` mit, der Build bricht ab, falls eines davon fehlt (#33).

Damit bekommt ein per USB-C angeschlossener PC oder Mac wieder eine Netzwerkverbindung zur Switch. Der eigenständige DHCP-Dienst bleibt maskiert, nur der L4T-Dienst startet ihn an der USB-Brücke `l4tbr0`.
