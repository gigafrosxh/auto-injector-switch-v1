Fehlerbehebungen nach dem ersten Start von Teria auf der Switch.

### Behoben
- **Start blieb hängen** (#31): Debian-systemd 257 läuft auf dem Switch-Kernel 4.9 nur mit `SYSTEMD_CGROUP_ENABLE_LEGACY_FORCE=1`; steht jetzt im Booteintrag.
- **Anmeldung ohne Tastatur unmöglich** (#32): Teria meldet sich automatisch an, der Anmeldebildschirm hat eine Bildschirmtastatur, es gibt keinen erzwungenen Passwortwechsel mehr.
- **Oberfläche startete nicht**: LightDM wartet nicht mehr darauf, dass logind den Bildschirm als Grafikgerät meldet; der Switch-Bildschirm (fbdev) ist als Grafikgerät von seat0 markiert.

### Neu
- **`teria-setup.txt`** auf der SD-Karte: WLAN-Name, WLAN-Passwort, eigenes Passwort und automatische Anmeldung am PC/Mac eintragen. Teria übernimmt die Werte beim Start und löscht die Passwörter danach aus der Datei.
- **Bootprotokolle** unter `teria-logs/` auf der SD-Karte, lesbar über Hekate → USB Tools → SD Card.
- **USB-Gerätemodus** ist eingeschaltet (Netzwerk über USB-C zum PC/Mac).

---
**Installation:** `teria-0.3.1-sd.zip` auf die FAT32-Partition der SD entpacken, vorher `teria-setup.txt` ausfüllen, dann Hekate → **Tools → Partition SD Card → Flash Linux** (nicht „Next Step“), danach **More Configs → Teria**. Anleitung: [docs/INSTALLATION.md](https://github.com/gigafrosxh/auto-injector-switch-v1/blob/v0.3.1/docs/INSTALLATION.md).
Teria schreibt nie auf den internen eMMC.
