# Teria-Oberfläche (Entwurf für 0.3.0)

Konsolen-Oberfläche für Teria: Startbildschirm mit Kachelreihe und großer Vorschau, Schnellmenü,
Bibliothek, Store, Einstellungen, Anmeldung und ein Desktop-Modus mit Dock. Gestaltet für 1280×720
(Handheld) und mit Joy-Cons bedienbar; Schrift ist Ubuntu, Akzentfarbe Teria-Türkis.

| Bibliothek | `teria-ui-3-bibliothek.png` |
| Store | `teria-ui-4-store.png` |
| Einstellungen | `teria-ui-5-einstellungen.png` |
| Anmeldung | `teria-ui-6-anmeldung.png` |
| Desktop-Modus | `teria-ui-7-desktop-modus.png` |

Alle Grafiken, Icons und Spielnamen sind eigene Entwürfe. `quelle/` enthält die Skripte, die Hintergründe
(`art.py`, braucht Pillow) und Bildschirme (`screens.py`, HTML) erzeugen.
